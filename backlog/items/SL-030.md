**Issue:** The deployed backend is Next.js/Vercel and there is no Worker runtime, Wrangler config, or Hono service boundary. Moving all routes in one step risks losing working features.

**Required outcome:** Define Cloudflare Worker entry points, Hono application structure, runtime-compatible dependencies, environment bindings, observability/error conventions, migrations/deploy process, and service boundaries based on Phase 2 domains. Decide the count based on independent deployment and ownership needs; do not use “32” as an unvalidated target.

**Completion checks:** A local Worker starts with non-production configuration; gateway and service health are observable; no Cloudflare private credential is checked in; the current frontend remains functional against its existing API while migration proceeds.
