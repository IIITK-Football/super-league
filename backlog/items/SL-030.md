## Assignment

**Entry point.** Run the real Wrangler Worker against local Supabase, then the identified staging release.

### Acceptance scenario

1. Check scoped public reads, missing/expired/tampered tokens, scoped writes, actor audit and atomic rollback. Record placement comparison and round trips required by D-04.

**Disposition: partial.** One modular Hono Worker serves shared handlers. The [Worker app](../../api/src/app.ts) validates write sessions, the [Wrangler configuration](../../api/wrangler.jsonc) separates environments, and [Worker tests](../../api/test/app.test.ts) cover health, scoped reads and session rejection. [SL-025](../../docs/walkthroughs/SL-025.md) records a staging smoke test. The deployment scripts and tests establish configuration intent and guard behavior. Use the [implementation plan](../../docs/plans/SL-030.md) for the evidence still needed.

**Remaining work:** Verify local Wrangler isolation and the hosted release identity, Auth and RLS behavior, transaction boundaries and audit attribution, credential isolation, connection behavior, and timing under [D-04](../../docs/decisions/D-04-workers-supabase-access.md). Inventory privileged call sites, including interactive writes, and resolve discrepancies with D-04. Prove health and error behavior in the single-Worker topology from [D-05](../../docs/decisions/D-05-worker-topology.md). Keep the frontend API contract functional throughout.

**Completion checks:** Run the local Worker against local Supabase with a scoped public read, a valid caller and missing, expired and tampered credentials. Verify denied writes leave nothing stored, a dictator write records its actor, and a failed multi-write rolls back. Verify private credentials stay out of browser bundles and the Worker build output. Record the deployed staging commit, health and a scoped request through Pages. Record the dashboard round-trip limit, timing and placement evidence or the outstanding owner decision before close-out.

**Usable in its own phase (rule R10):** Not applicable. This is runtime infrastructure.
