## Assignment

**Entry point.** Contributor opens a foundations PR with a public division page and phone scorer example.

### Acceptance scenario

1. Owner reviews visual direction, tokens, primitives, interaction states, contrast, keyboard focus and reduced motion at phone, tablet and desktop sizes.

### Foundations review

Show a representative public division page and phone scorer workspace using the same tokens and primitives. Include public navigation and section states, match score and controls, keyboard focus, error and loading states. Present examples at phone, tablet and desktop widths and collect owner approval before page rollout. Individual page adoption is verified in the rollout items.

**Issue:** Current visual styles are inconsistent and the user reports that the site looks poor. Individual page restyling without shared design rules would preserve inconsistency.

**Required outcome:** Research the referenced SBB design-system guide and the user's referenced Impeccable style skills; choose a distinct visual direction; define tokens, typography, color, spacing, layout, responsive breakpoints, component states, motion, accessibility, and usage rules before rebuilding pages.

See the [contributor issue](https://github.com/IIITK-Football/super-league/issues/187).

**Completion checks:** The design system has documented foundations and reusable primitives; key pages use the same system; no page gets an ad hoc visual language without documented reason.
