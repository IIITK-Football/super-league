**Issue:** The current hero uses hard-coded multi-clip R2 assignments and the home uses a static news grid rather than the requested configurable video/news experience.

**Required outcome:** Use hls.js for one long/chaptered video presentation with division timeline segments, side-scrolling division selection, rotating start timestamps, selected-division resume/autoscroll, and one retained player during vertical scroll/parallax transitions. Only the current season gets the first video. Show news images and text as sliding home content, with additional homepage sections below to be finalized by the product owner.

**Responsive behavior:** Use horizontal video on wide screens; define a tested mobile presentation that rotates or reframes the video without zoomed/cropped faces or controls. Provide keyboard/touch controls, reduced-motion handling, pause behavior, captions/meaningful labels where available, and poster/error fallback.

**Completion checks:** User can move between division chapters without a full player reset; vertical scroll does not restart playback; newest season is first; configured order is respected; no production R2 URL is hard-coded.

**Scope note (rule R10):** the first usable flows come from their owning items (SL-060). This item consolidates, visually redesigns and refines those flows; it does not make them usable for the first time. Any capability still lacking a usable flow is a defect of its owning item.

**Consolidated (2026-11-18):** the configurable home order, lead video, news carousel and World Cup entry already work through SL-060, which also resolves D-07 and D-11 for that first version. Media come from the Phase 3 storage system. This item redesigns the presentation: chaptered HLS, side-scrolling division selection, resume, parallax and motion.

**Home standings snapshot parity (added 2026-11-21):** the home page's "Top 4 Standings" snapshot (from `GET /api/home/dashboard`) and the division's Full Table (from `GET /api/standings`) are computed separately today.
- *Owner-observed in production; cause unconfirmed:* the home "Top 4 Standings" showed zero points and zero goal difference for every team while the Full Table for the same division showed the correct values.
- Required: for the same division and season, the home snapshot agrees with the Full Table on the teams shown, their order, points and goal difference (the snapshot is the Full Table's top four, not a separate calculation that can drift).
- Required: a failed query or missing data shows an understandable error or empty state; it never renders as a valid-looking table of zeros.

**Completion checks for the snapshot:**
- An integration test against the local stack compares `/api/home/dashboard` with `/api/standings` for the same division and season (teams, order, points, goal difference), including a season with completed and awarded results.
- A test proves that a failed standings query produces an error or empty state, not an all-zero table.
- The home page and the Full Table are checked side by side on staging for each division with a current season.
