**Issue:** The sole existing workflow installs with npm, uses a mutable Ubuntu runner, captures some nonexistent paths, and uploads directly to R2 on each `main`/`develop` push. The user has reported a Playwright runner issue.

**Required outcome:** Reproduce the failure after the frontend routes and design are settled; align Node, pnpm, Playwright package, and installed browser versions; use the real route inventory; isolate screenshots as an artifact/check or a protected upload step rather than making every application push mutate production R2.

**Completion checks:** CI runs deterministically on a supported pinned environment; expected pages are captured; failures are surfaced; upload only runs for the intended deployment environment and has least-privilege storage credentials.
