## Assignment

**Entry point.** Dictator opens Divisions and Seasons at /dictator. A visitor uses /<division> or /<division>/<season>.

### Flow and screen sketch

- Dictator sidebar → Divisions → list with Hidden, Public, and Archived states → division detail with identity, branding, visibility and season order → season detail with dates, sections and lifecycle actions.
- Public navigation → division → current season if visible and unarchived, otherwise a season picker. A published division without public seasons shows “No public seasons yet.” The explicit season URL opens the requested public season.
- Section settings → editable label, order, Enabled and Show in navigation → visitor sees the same configuration after refresh.

Use a list/detail layout inside the existing dictator dashboard. Keep the selected division and season visible above settings. Place visibility and current-season actions beside the state label and keep section ordering controls in the section list. The public view uses the division branding, season picker when needed, and the configured navigation rows.

### Acceptance scenarios

1. In a new data-driven division and in an existing division, create two seasons. The division and new seasons start hidden. Publish each independently. Make a visible, unarchived season current in one atomic action. The other public season remains accessible by explicit URL.
2. Hide or archive the current season and verify its current flag clears in the same write. The public division opens the picker. Restore the season to hidden; show it publicly explicitly and make it current explicitly if desired. Hiding the division itself suppresses all children publicly and retains their configuration. The dictator can still access historical records.
3. Disable a section and verify both its public route/API and navigation entry are unavailable. Keep a section enabled but remove it from navigation and verify the direct URL works. Preserve current behavior for optional features outside this slice; a newly configurable module is activated only after its owning feature ships.
4. Reject invalid input and unauthorized callers. A failed creation rolls back the default section creation and season together. A failed update leaves stored configuration intact. Audit changes through caller-scoped Worker writes and retire the corresponding direct dashboard writes.

**Release scope.** Configuration, visibility, branding and navigation. Versioned rules belong to [SL-044](SL-044.md); competition calculation belongs to [SL-054](SL-054.md).
