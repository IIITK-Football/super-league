## Assignment

**Entry point.** Dictator, captain and scorer open their own redesigned workspaces.

### Acceptance scenario

### Screen sketch

Separate role entry points → dictator configuration hub, captain team workspace, and phone scorer match list and controls. Each workspace uses the primitives from SL-090 and retests the owning scenarios.

**Issue:** The working surfaces grew inside the old "Admin Command" dashboard and follow its patterns. Each capability is usable, but the workspaces are not designed as coherent, role-specific products.

**Required outcome:**
- Redesign the dictator configuration workspace, the captain/team-details workspace and the scorer match-operations workspace on the SL-090 design system, following the Phase 0 role boundaries.
- Provide clear account/player confirmation and link status, draft previews, and understandable authorization errors.
- Normal users see only account and public/fantasy features.

**Completion checks:**
- Each surface displays only permitted operations.
- Authorization errors are understandable.
- Mobile, tablet and desktop layouts work.
- Every owning item's flow still passes its UI, API and database tests after the redesign.

**Scope note (rule R10):** this item consolidates, visually redesigns and refines flows that already work. It does not make anything usable for the first time. Any capability still lacking a usable flow is a defect of its owning item.
