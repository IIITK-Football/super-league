**Issue:** The current surface is called Admin Command, scorer is mislabeled admin, and match operations are not safely separable from general management.

**Required outcome:** Build dedicated dictator configuration, captain/team-details, and scorer/match-operations workspaces that reflect Phase 0 role boundaries. The dictator workspace must preview draft rules/forms before publishing, manage registration windows/capacity/waitlists, review registration status and integrity reports, export authorized division/season data, and include dictator-only player/account link/unlink controls from SL-042. Provide clear account/player confirmation, link status, and scoped scorer assignment/revocation. The scorer workspace must be mobile-friendly, present clear match data and an event timeline, and show online/offline/pending-sync/conflict state. Normal users see only account and public/fantasy features.

**Completion checks:** Each surface displays only permitted operations; authorization errors are understandable; mobile/tablet/desktop layouts work; scorer can complete the full match-edit and offline-sync workflows without a dictator dashboard; captains cannot manage player records; only dictators can link or unlink a player account, manage registrations, publish configuration, export data, and assign/revoke scorers.
