**Issue:** Current pages diverge by `mens`/`womens`/`freshers`, and the same feature set is not available uniformly.

**Required outcome:** Present one division experience driven by the selected division and season, with enabled sections from dictator configuration. Combine Freshers' team builder/captain tools with the strongest current WSL/Super League match, standings, and fantasy functionality. Preserve shareable division/season URLs and historical season selection.

**Legacy cleanup:** Remove the `freshers_fixtures` runtime dependency (`RoadToFinal.jsx`, `ManageRoadToFinal.jsx`) by moving that behavior onto the canonical match/bracket data; the table is absent from hosted Supabase (owner-verified). Final retirement check is SL-102.

**Completion checks:** All divisions expose the same core feature model; feature variation comes from validated configuration; adding a season does not require a new hard-coded route; no division's existing supported capability is lost. When a division has both league and knockout phases, users can switch between them; when only one exists, no misleading phase toggle is shown.
