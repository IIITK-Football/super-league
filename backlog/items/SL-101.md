**Issue:** Local correctness does not prove a safe production transition. The app has historical teams, players, match events, predictions, and media URLs that must retain integrity.

**Required outcome:** Run the approved mapping against a production-derived staging copy, reconcile counts and key relationships, validate role mapping, verify images/media, rehearse rollback, and obtain the required review before deploying schema or API cutover.

**Completion checks:** Counts and referential checks pass; seeded fixtures remain local-only; production migration is forward-only or has an approved rollback strategy; required data-retention artifacts remain intact and access-controlled.
