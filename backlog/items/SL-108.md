## Assignment

**Entry point.** An assigned scorer opens an online match before losing connectivity. A dictator opens scorer assignments to copy an invite.

### Flow and screen sketch

- Phone match workspace → Offline / Pending sync banner → queued actions → conflict comparison or read-only unsynced list.
- Dictator → Scorer assignments → select verified account and scope → generate and copy expiring invite. Recipient → invite URL → sign in as intended account → accept.

### Acceptance scenarios

1. Load an assigned match online, go offline, record actions and reload. A minimal match snapshot and durable action queue return with pending status. Sync uses stable action IDs; retry or duplicate receipt applies an action only once.
2. When a queued edit conflicts with the server version, keep the public server result. Show both versions. A still-assigned scorer may discard the action or explicitly submit a correction against the displayed server version. If that version changes again, show the new conflict.
3. When assignment expires or is revoked before reconnect, reject match writes and keep actions in a read-only local unsynced list. Recheck caller and assignment server-side on every sync action.
4. The copyable invitation binds one verified account to its intended match or season. Accept only when signed in as that account. Reject wrong account, expired, consumed or revoked invitations. Verify acceptance grants scoped scoring only and audit invitation and match changes.
