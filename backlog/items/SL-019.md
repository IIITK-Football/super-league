**Status:** In progress (2026-11-17). Started under an approved plan before the gates existed, so it is marked legacy; its plan is docs/plans/SL-019.md.

**Issue:** The development process was described only in Markdown, so nothing stopped a change from skipping tests, hooks, a plan or a walkthrough, and the process files were not tracked or checked by CI.

**Required outcome:** Project-wide gates enforced by scripts, hooks and CI rather than instructions: strict test rules, Git hygiene hooks, a tracked backlog with Definition of Ready and Done and a status machine, structured completion walkthroughs, Claude Code guard rules for the safety boundaries, and one required CI check, with an audit that verifies it all.

**Completion checks:** Each gate is proven by a negative test that must reject the bypass; the GitHub ruleset is applied by the owner and the audit passes.
