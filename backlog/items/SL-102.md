**Issue:** Keeping old Next endpoints, Freshers-only fixture assumptions, duplicate role names, and old bucket settings indefinitely creates two sources of truth.

**Required outcome:** After the cutover window, remove legacy code/config in separate atomic changes: Next/Vercel API deployment, legacy Freshers fixture usage, obsolete `admin`/`editor` aliases, duplicate match-event fields if migrated, old R2 hosts/keys, and stale docs/workflows.

**Completion checks:** Search confirms no runtime dependency remains on each retired surface; production traffic and rollback window are accounted for; data/archive retention is respected; each deletion has a specific reviewable commit.

**Already retired in SL-020 (owner instruction 2026-11-19, migration `20261122000000`):** the legacy `division` columns on teams, matches and registrations, the per-division flair columns, the compatibility triggers and `legacy_division_map`, the views `top_scorers`, `league_standings` and `league_schedule`, and the unused `polls`/`poll_options`/`increment_vote`. Production receives that migration only through the reviewed `main` release; its guards stop it unless every record is attached to a season and polls are empty.
