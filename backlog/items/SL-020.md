**Issue:** Division strings currently identify the experience, so a new division or season requires additional conditionals, routes, and possibly tables.

**Required outcome:** Define division and season records with stable identifiers, display names, dates/status, ordering, visibility, format, and relationships. Provide configurable sections/features and settings such as fantasy availability, league/knockout phases, news placement, video chapter, rules, branding, and navigation visibility.

**Division-agnostic requirement (owner decision 2026-11-16):** A dictator can create and configure any division (e.g. Inter, Pradhva, future ones) from the dashboard with no code branch, enum/check-constraint change, route, or migration. Each division has multiple seasons and its own enabled features, rules, branding, registration settings, and format. Inter has not started: no Inter data is preserved and no Inter division is created from the legacy value.

**Completion checks:** Men's Super League, WSL, and Freshers are ordinary division records, and a new division (e.g. Inter) can be created through the dictator path with zero code or schema changes (acceptance test creates one); World Cup remains separate; no hard-coded route or enum branch exists per division; two seasons can coexist for one division; hidden/archived status is defined separately from deletion.
