## Assignment

**Entry point.** Scorer opens the phone workspace from the signed-in account menu or an assigned match link.

### Flow and screen sketch

- Signed-in scorer → Scorer workspace from account menu or direct match link → assigned match list with Live, Upcoming and Recent groups.
- Match workspace → persistent teams, score and timer/status → one-tap goal on either side → recent events with add attribution, correct and void → match controls and final result. Show a clear error after a failed save; refresh to the accepted server state.

On a narrow phone screen, put the two goal actions in the score row, status and time immediately below, and the timeline next. Use the timeline to handle attribution and corrections so the common goal action stays available.

### Acceptance scenarios

1. Dictator grants and revokes access with the existing assignment UI. An assigned scorer sees only matches allowed by their live assignment. An empty list explains the lack of assignments. An unassigned, expired, revoked or signed-out caller cannot edit, including by direct request.
2. On a phone, award one goal immediately when scorer and assist are unknown. The public match score changes with the unattributed event. Later attribution updates the displayed event and player stats without adding another goal.
3. Add and correct goals, own goals, cards, assists and match status/timer/minute. Void mistaken events using the existing event rules. Set or correct the final result, including awarded results and separate shootout totals. A correction flags fantasy regrading for the dictator where required by D-08.
4. Confirm stored changes have the signed-in actor and scorer scope does not grant team, roster, editorial, user, division or fantasy management. Replace the scorer's use of the dictator live tab after the dedicated workspace is verified.

See the [contributor issue](https://github.com/IIITK-Football/super-league/issues/185). Online workspace ships here. Offline sync, conflict resolution, and account-bound invitations belong to [SL-108](SL-108.md). Visual redesign belongs to [SL-092](SL-092.md).
