**Issue:** Open Graph/match messaging relies on fixed paths, names, and images. The requested WhatsApp link should resolve predictably to live or upcoming match and allow dictator copy/image selection.

**Required outcome:** Dictator selects or configures the target match rule (explicit assignment, active live match, else next scheduled match), message text, image, and share destination. Support fallback when no match is available.

**Completion checks:** Share-link resolution is deterministic across zero/one/multiple live matches; content is editable without a code change; link preview metadata agrees with the selected match and published image.

**Usable in its own phase (rule R10):** this item is not complete until a dictator configures share destinations and copy, and the match share action uses them. The flow follows the current frontend patterns (no redesign), exposes the real authorized action, handles loading, empty, success and error states, and is verified through the real UI, API and database path (allowed and denied cases) locally and on staging. Phase 9 only consolidates and refines it.
