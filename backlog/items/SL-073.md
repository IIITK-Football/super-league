**Issue:** Current bucket names and public URLs are hard-coded/documented in inconsistent places. Disabling them immediately would break current production media.

**Required outcome:** Select final names and ownership for the eight requested storage purposes; copy and verify object inventories; update database URLs, worker bindings, CI, and documentation; configure the purchased domain for R2 only while the website remains on Pages.dev.

**Completion checks:** Counts/checksums and sampled object reads match before/after migration; media URLs work on the target domain; the website domain remains Pages.dev; rollback is possible until verification completes.
