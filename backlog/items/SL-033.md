**Issue:** Current backend uses Next server clients, cookies, direct Supabase JS calls, and service-role secrets. Those execution assumptions do not automatically transfer to Workers.

**Required outcome:** Select and document the supported database/Auth access path for Workers, token forwarding, transaction/connection strategy, and privileged operations. Keep Supabase Auth if chosen, but avoid assuming a Node-specific database driver or Next cookie behavior works unchanged in Workers.

**Completion checks:** Local Worker calls only the local/test Supabase project; auth validation and scoped user identity are tested; database limitations, connection strategy, and privileged operations are documented.
