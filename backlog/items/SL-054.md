**Issue:** Existing bracket behavior is competition-specific and match ordering cannot safely determine a team's bracket slot.

**Required outcome:** Calculate league standings and configured advancement, allow league-only/knockout-only/combined modes, map actual matches to editable bracket positions, support penalty results and corrected results, and regenerate downstream slots without destroying manual mapping.

**Completion checks:** Bracket tests cover ties, penalties, missing/unplayed results, result corrections, all supported formats, and administrator edits; bracket state remains stable when matches are reordered.

**Usable in its own phase (rule R10):** this item is not complete until a dictator maps and re-maps matches to bracket positions, and visitors see the bracket. The flow follows the current frontend patterns (no redesign), exposes the real authorized action, handles loading, empty, success and error states, and is verified through the real UI, API and database path (allowed and denied cases) locally and on staging. Phase 9 only consolidates and refines it.
