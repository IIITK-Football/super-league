**Disposition: partial.** The [Worker route table](../../api/src/routes.ts) mounts the compatibility surface. [Next runtime scripts and dependencies](../../backend/package.json) and the shared handlers are still present. Their presence does not establish whether an obsolete deployment still serves any caller.

**Completion checks:** Verify all supported API routes through the Worker and explicitly document production and preview routing. Inventory remaining Next-only callers, routes, and deployment assumptions. Exercise rollback to a prior compatible Worker and Pages release, then retire the obsolete Next deployment and runtime dependencies after verified parity and the rollback window. Preserve shared handlers until their Worker imports are safe. Any production action remains owner-approved.
