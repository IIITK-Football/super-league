**Issue:** Division-specific sections are hidden in code conditionals, and users cannot consistently add/remove pages per competition.

**Required outcome:** Store allowed sections, labels, order, rules, and visibility per division/season. Build the rules page from a library of premade visual components (for example, titled rule sections, eligibility callouts, numbered steps, tables, and highlighted notices). Dictators choose which components appear, enter content through structured fields, and control their order and visibility in the dashboard. Provide draft/publish states, a player-facing preview, and version history so changes do not rewrite previously accepted rules. Do not require Markdown authoring. Support shared modules for schedule/results, standings, teams/rosters/team builder, profiles, division fantasy, predictions/leaderboards, polls, newsletter/articles, legends/archive, and rules; dictators can enable, hide, and reorder available modules. Do not allow configuration to expose an unauthorized operation.

**Completion checks:** A division's navigation and public section list come from validated configuration; dictators can assemble a polished rules page from premade components without writing markup; drafts can be previewed before publishing; a published rules version remains available for registration acknowledgments; the public page follows the selected order and content; hiding a division or component is reversible; a missing optional module does not break the shared experience.
