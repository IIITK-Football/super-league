**Issue:** Match JSON fields and the `goals` relation overlap; event edits and derived totals can diverge. Cards and unknown scorer/assist states are not represented as first-class match events.

**Required outcome:** Define one canonical event history for goals, own goals, assists, cards, minute/time, corrections, and score state. Specify whether score is derived from events or can be explicitly set by a scorer and reconciled afterward. Preserve unknown/unassigned scorer and assist states.

**Completion checks:** Goal, assist, own-goal, scoreline, standings, and fantasy calculations all use documented canonical rules; edits and correction history are traceable; null/unknown attribution is distinct from an event that does not exist.
