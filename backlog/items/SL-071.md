**Issue:** Per-route R2 clients and hard-coded public URLs make local testing and future provider changes fragile.

**Required outcome:** Define one server-side storage interface for upload, signed upload, read/public URL, and object metadata. Provide separate bucket binding/config values for `backup`, `fresher-images`, `intro`, `news-images`, `player-images`, `playstyles`, `screenshot`, and `team-logos`. Provide a separate public base URL for each bucket that is intentionally public. Keep the backup bucket private and server-only even if it needs its own endpoint/binding value; never expose its URL or credentials through a browser variable.

**Completion checks:** Routes do not construct independent R2 clients; each media purpose resolves to one configured bucket; missing settings fail clearly; local, develop, and production configuration are isolated.
