# SL-040 Division and season configuration

## Summary

Dictators can create, publish, hide, archive, restore, and reorder divisions and seasons. Season creation saves the default sections in the same transaction. Public navigation reflects season configuration. Visitors can open a published season directly and see a picker if the division has no current season.
