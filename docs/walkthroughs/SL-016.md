## Summary

Students can now sign in with a college email and password as well as Google. Only @iiitkottayam.ac.in addresses are accepted, enforced by the trusted login route before Supabase Auth is contacted and again by a database trigger on auth.users, so a direct call to Supabase cannot bypass it. Adding a password to an existing Google account keeps the same user id. Password sign-in, sign-up and reset all use Cloudflare Turnstile, and the login page handles each state.
