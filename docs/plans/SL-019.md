# Plan: enforce the development workflow with tooling

Approved by the owner on 2026-11-17 (interactively, before `pnpm work approve` existed; the item is marked legacy for that reason).

## Issue
The development process lived only in Markdown (`CLAUDE.md`, a workflow-plugin adaptation file, the backlog's section 4). Nothing stopped a change from skipping tests, hooks, a plan or a walkthrough. The Git hooks were opt-in with an agent-settable bypass, test selection was path-based so unmapped files went green, pending groups passed vacuously, CI was not a required check, and the process files themselves were git-ignored.

## Evidence
- `core.hooksPath` was unset; `SKIP_HOOKS` skipped every hook.
- 56 of 325 tracked files mapped to no test group; 5 of 10 groups were pending and reported as passing.
- No ruleset required a pull request or any check on `develop` or `main`.
- No Definition of Ready, Definition of Done or walkthrough existed anywhere.

## Scope
1. Strict test groups (mapped, covered, tested) with approved exemptions only.
2. Hygiene shared by hooks and CI; automatic hook install; a pre-push gate; no bypass.
3. A tracked backlog with machine-readable items, phase gating, Definition of Ready and a status machine (`pnpm work`).
4. Completion walkthroughs generated from evidence and validated.
5. Claude Code guard rules and permissions for the safety boundaries and the gates.
6. One required CI check (`gate`) and a read-only `pnpm work audit`.
7. Documentation, and removal of the superseded process files.

Out of scope: product features, the next phase, and anything hosted. Applying the GitHub ruleset is the owner's step.

## Acceptance checks
Each gate has a negative test that must reject the bypass (see the item's checks). The owner applies the ruleset, and `pnpm work audit` then passes.

## Tests
`backend/tests/tooling/*` (the tooling group): strict test rules, hygiene and hooks, front matter, the backlog model, the `work` commands, the walkthrough, the Claude guard, the CI gate and the audit. The full `pnpm test:all` run stays green.

## Rollback
Everything is repository files and local Git configuration. `pnpm hooks:uninstall` removes the hooks. Reverting the commits restores the previous process. The ruleset is removed in GitHub settings.
